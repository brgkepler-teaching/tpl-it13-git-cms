Dieser Beitrag ist eine ganz normale **Markdown-Datei**. Oben zwischen den Strichen steht das *Frontmatter* mit den Daten
(Titel, Datum, Autorin). Darunter folgt der eigentliche Text.

Jede Änderung an dieser Datei ist ein Git-Commit. Dadurch sehe ich später genau, wer was wann geändert hat, und kann
Fehler mit einem Klick rückgängig machen. Eine Datenbank oder einen Server brauche ich dafür nicht.
